## 📁 Committed Projects & Practice Files

### 📂 `loops_practice/`
Daily practice exercises focused on mastering Python loop constructs.

- **`for/code1.py`** — Basic `for` loop using `range()` to print numbers 0–4.
- **`for/code2.py`** — Function `print_numbers()` that uses a `for` loop with `range(200)` to print 0–199, with a simple test runner included.

---

### 📂 `list/`
Exercises exploring Python list operations and unpacking.

- **`code1.py`** — Demonstrates **list unpacking** using the `*` (starred) operator to separate the first element from the rest of a list.
- **`code2.py`** — Demonstrates **positional list unpacking** by assigning each element of a list to individual variables (`name`, `age`, `job`).
- **`code3.py`** — Comprehensive reference covering core **list methods**: `append()`, `extend()`, `insert()`, `pop()`, `clear()`, `sort()`, `sorted()`, `reverse()`, `reversed()`, and `index()`, each with inline comments and examples.

---

### 📂 `project_1(loops)/`
First mini-project set, applying loops to build real interactive programs.

- **`area_calculator1.py`** — A simple **Area Calculator** that uses `if/elif/else` conditionals to compute the area of a circle, rectangle, triangle, or square based on user input.
- **`area_calculator2.py`** — An enhanced version of the Area Calculator using a **`while` loop with a menu** (choices 1–5), allowing the user to calculate areas repeatedly until they choose to quit.
- **`rock_paper_sissor.py`** — A **Rock, Paper, Scissors** game using the `random` module and a `while` loop. The computer picks a random choice each round, the result (win/loss/tie) is displayed, and the player can choose to play again.

## 🛠️ How to Run

Make sure Python 3 is installed, then run any script directly:

```bash
python3 loops_practice/for/code1.py
python3 project_1\(loops\)/area_calculator2.py
python3 project_1\(loops\)/rock_paper_sissor.py
```
